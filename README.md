# RRB JE Question Bank

Responsive RRB JE practice bank with clickable MCQ answers, progressive rendering, search, topic filtering, year filtering, and dark mode.

## Current database
- 2026: 595 questions (Numerical Ability, Reasoning, General Science)
- 2024: 248 Numerical Ability questions from the supplied topic-wise Mathematics PDF
- Total: 843 questions

### 2024 Mathematics topics
Number System; L.C.M and H.C.F; Simple and Compound Interest; Discount; Ratio and Proportion; Average; Percentage; Distance, Time, and Speed; Profit and Loss; Algebraic Identites; Mensuration; Data Interpretation; Statics.

For the 2024 questions, the cards intentionally show **only the topic pill**; no shift/time metadata is attached. The source PDF contains one incomplete Number System entry at the end (Q30 shows options/answer but no readable question text), so it was not added as a question record.

## Files
- `index.html` — page shell
- `css/style.v4.min.css` — styles and dark mode
- `js/app.v4.min.js` — filtering, progressive rendering, answer interaction, theme and year filter
- `data/questions.json` — human-readable master database
- `data/questions.v4.min.json` — production JSON
- `assets/railway-logo.webp` — logo
- `_headers` — Netlify caching rules
- `robots.txt`, `sitemap.xml` — SEO files
